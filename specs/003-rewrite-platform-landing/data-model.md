# Modelo editorial estático — 003

No hay datos de runtime ni esquema persistido. El modelo es contenido JSX/HTML:

- **Brand**: nombre obligatorio «Organigrama Abierto»; disclaimer obligatorio «iniciativa independiente», «en construcción», no canal oficial. Ningún emblema o dominio estatal.
- **Section**: orden fijo `top → problema → metodo → para-quien → plataforma → principios → cierre → footer`; cada id enlazado debe existir exactamente una vez; Plataforma se conserva sin cambios.
- **Primary action**: etiqueta exacta «Conoce la plataforma», destino exacto `#plataforma`; solo una acción principal en el hero.
- **Principle**: título y descripción legibles; mínimo tres: dato con fuente, neutralidad (enlazar sin opinar), protección de datos personales.
- **Method**: ciclo fuentes oficiales → validación humana → publicación periódica; cobertura aprobada por los tres poderes, excepción de autónomos; corte lunes con validado hasta viernes.

Restricciones: español editorial; sin autoridades concretas, cifras, normas específicas, fechas de lanzamiento, emails ni enlaces externos; contenido esencial disponible sin JavaScript.

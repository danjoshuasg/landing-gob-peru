# Investigación y decisiones editoriales — Organigrama Abierto

## Secciones y trazabilidad

| Origen | Destino | Decisión |
|---|---|---|
| Hero | Hero reescrito | Marca, explicación para ciudadanos y periodistas y una sola acción principal. |
| Visión | Problema reescrito | Información pública sobre cargos dispersa y susceptible de quedar desactualizada. |
| Método | Cómo funciona reescrito | Fuentes oficiales → validación humana → publicación periódica. |
| Capacidades | Fusionada con Roles | La imagen y el contexto pasan a «Para quién»; deja de existir como sección propia. |
| Roles | Para quién reescrito | Ciudadanos y periodistas, con el contexto de Capacidades. |
| Territorio | Sin sección propia | Su imagen pasa a «Para quién», antes de Plataforma. |
| Plataforma | Sin cambios | Conservar contenido y diagramas de la spec 002. |
| Principios | Reescritos | Cada dato con fuente, neutralidad y protección de datos personales. |
| Cierre | Reescrito | Iniciativa en construcción, sin fechas ni promesas; invitación interna. |
| Footer | Reescrito | Marca independiente y enlaces internos válidos. |

Orden: hero → problema → cómo funciona → para quién → Plataforma → principios → cierre → footer.

## Alcance comunicado en «Cómo funciona»

- Ejecutivo: hasta direcciones de línea; organismos adscritos, solo alta dirección.
- Legislativo: mesas directivas, parlamentarios, presidentes de comisión y alta dirección administrativa.
- Judicial: Presidencia, jueces supremos, presidentes de cortes superiores y gerencia general.
- Organismos constitucionales autónomos: fuera de esta primera versión.

## Actualización, validación y acción

El corte semanal se realiza los lunes con lo validado hasta el viernes. Cada cambio pasa por validación humana en el backoffice antes de publicarse; la página describe el proceso previsto, no una base de datos operativa. Acción principal única del hero: «Conoce la plataforma» → `#plataforma`. El cierre puede remitir a esa misma sección sin presentar una segunda acción principal ni una vía externa ficticia.

No se afirman cifras, nombres de funcionarios, normas específicas, fechas de lanzamiento ni enlaces externos. La categoría genérica «normas» de Plataforma no constituye una norma específica y queda intacta.
